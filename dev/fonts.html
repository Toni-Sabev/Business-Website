§1 — Audit result (stated plainly)

The premise in this task's "Context" section does not match the live site. I checked styles/tokens.css as it exists right now: the live BG (default) typeface is PT Serif for both --font-display and --font-body, and the EN override (html[lang="en"]) is Playfair Display / Inter. Both of those were set earlier this session after live A/B testing on the actual site and were explicitly approved.

"Source Serif 4" + "Manrope" is not, and was never, the live pairing. That combination only exists in one place in this repo: files/sevis-i20-f1-lifecycle.html — a dev-only, non-deployed snippet (per the project wiki, files/ is explicitly excluded from production). So there is no "silent fallback to Georgia" bug to report on the live site for that pairing, because it was never requested by any live page in the first place.

That said, I ran the actual check the task asked for, applied to the real candidate: I fetched Google Fonts' own CSS for Source Serif 4 with a Chrome user-agent and confirmed the response includes a real /* cyrillic */ @font-face block (not just latin/latin-ext) — so if this pairing were ever wired up, it would not silently fall back to Georgia. It also has a proper locl feature with a dedicated BGR language-system entry in its GSUB table (verified below, not assumed) — so it does actively adapt shapes for lang="bg".

§3 — Bulgarian letterform (locl) results — real GSUB data, not assumptions

I downloaded each candidate's actual Cyrillic-subset .woff2 file and parsed its GSUB table with fontTools, looking for a locl feature registered under a BGR (Bulgarian) language-system for the cyrl script. This is the mechanism that makes a font's glyph shapes actually change when an element carries lang="bg". A font without it renders one fixed glyph set no matter what lang says — that shape may or may not already look Bulgarian by design; only your eyes on the glyph row below can settle that part.

This task's own §3 prior guess ("expect PT Serif and Golos Text to pass, expect Playfair Display and Cormorant Garamond to fail") does not match what's actually in these font files:

  • Has real BGR locl (PASS): Lora, Cormorant Garamond, Vollkorn, Unbounded, IBM Plex Sans, Commissioner, Source Serif 4, Manrope
  • No BGR locl (fixed glyph set): PT Serif, Literata, Playfair Display, Golos Text, Onest

Notably PT Serif and Golos Text — both genuinely Cyrillic-native fonts — ship a single default glyph set with no OpenType-level Bulgarian/Russian switching at all (their designers likely picked one default and didn't need to branch it), while Cormorant Garamond, of all things, does carry a real BGR substitution table. Judge the actual rendered shapes in each specimen's glyph row below — that's the real test.
